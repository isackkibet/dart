# Controlled Pilot Plan

## Pilot scope

Start with controlled pilot only.

## Recommended pilot limits

- selected creators only
- selected YohPal Live internal testers
- limited room duration
- one broadcaster per room
- limited viewers per room
- no monetization
- no public creator rollout
- daily technical review

## Pilot duration

Recommended:
```text
7 days
```

### Daily checks

- active rooms
- failed joins
- failed media starts
- producer failures
- consumer failures
- TURN ratio
- device failures
- user complaints
- crash logs

### Scale decision

Move beyond pilot only when:
- failure rate is acceptable
- supported devices are certified
- operations team understands incident response
- support team has known issue responses
- rollback plan is approved
