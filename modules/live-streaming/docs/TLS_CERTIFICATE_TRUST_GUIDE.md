# TLS Certificate Trust Guide

WebRTC requires secure origins.

For local development, nginx serves HTTPS/WSS using a self-signed certificate.

## Certificate files

Generated by:

```bash
npm run certs
```

Files:
- `docker/certs/localhost.crt`
- `docker/certs/localhost.key`

## Browser testing

Open:

```
https://<LAN_IP>/health
```

Accept the browser warning for the self-signed certificate.

## Android physical device

1. Copy `docker/certs/localhost.crt` to the Android device.
2. Open Android Settings.
3. Search for "Install certificate".
4. Install as a CA certificate.
5. Restart the browser/app if needed.
6. Open `https://<LAN_IP>/health` in Chrome and confirm no blocking error remains.

Some Android versions require a device lock screen before installing a user CA certificate.

## iOS physical device

1. Send `docker/certs/localhost.crt` to the iPhone.
2. Open the certificate file.
3. Install the profile.
4. Go to: Settings > General > About > Certificate Trust Settings
5. Enable full trust for the installed certificate.
6. Open `https://<LAN_IP>/health` in Safari.

## Flutter apps

The Flutter app must connect to:

```
wss://<LAN_IP>/ws
```

If certificate trust is not installed correctly, the WebSocket connection may fail silently or show a TLS error.
