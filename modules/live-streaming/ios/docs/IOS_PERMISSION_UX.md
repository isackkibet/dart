# iOS Permission UX

Before requesting permissions, YohPal Live should explain:

```
YohPal Live needs access to your camera and microphone so you can broadcast live video and audio to your viewers.
```

If camera permission is denied:

```
Camera permission is disabled. Please enable Camera access in iPhone Settings to go live.
```

If microphone permission is denied:

```
Microphone permission is disabled. Please enable Microphone access in iPhone Settings so viewers can hear your stream.
```

For local prototype testing:

```
YohPal Live also needs access to your local network so it can connect to the local streaming server during development testing.
```
