3Migration Adapter Contract

Every module creates one class implementing this contract. The five validation methods prove that the module correctly consumes each shared service rather than its own duplicate.

abstract class YohPalModuleMigrationAdapter { String get moduleName; Future<void> validateSharedIdentity(YohPalPlatformProvider platform); Future<void> validateSharedWallet(YohPalPlatformProvider platform); Future<void> validateSharedBrain(YohPalPlatformProvider platform); Future<void> validateSharedAnalytics(YohPalPlatformProvider platform); Future<void> validateSharedDeepLinks(YohPalPlatformProvider platform); }
4YCIOS Reference Adapter

The YCIOS adapter is the template all other modules should follow. Each validation method exercises a real shared service call — not a mock.

class YciosMigrationAdapter implements YohPalModuleMigrationAdapter { @override String get moduleName => 'ycios'; @override Future<void> validateSharedIdentity(platform) async { await platform.identity.getCurrentIdentity(); } @override Future<void> validateSharedWallet(platform) async { final identity = await platform.identity.getCurrentIdentity(); if (identity != null) await platform.wallet.getBalance(identity.uid); } @override Future<void> validateSharedBrain(platform) async { await platform.brain.execute( agent: 'ycios', task: 'health_check', input: {'source': 'phase16'}, module: moduleName, ); } @override Future<void> validateSharedAnalytics(platform) async { await platform.analytics.track( event: 'module_migration_validated', module: moduleName, ); } @override Future<void> validateSharedDeepLinks(platform) async { final link = platform.deepLinks.build( module: 'ycios', entity: 'project', id: 'test', ); final parsed = platform.deepLinks.parse(link); if (parsed?.module != 'ycios') throw StateError('Deep link validation failed.'); } }
5Required Module Access Pattern

Every screen and service in a migrated module accesses shared infrastructure through the provider — never through a locally constructed duplicate.

✕ Before (duplicate services)
final auth = HustleAuthService(); final wallet = HustleWalletService(); final ai = HustleAIClient(); final search = MarketSearchService(); final analytics = LiveAnalyticsService();
✓ After (shared platform)
final p = YohPalPlatformProvider.of(context); final identity = await p.identity.getCurrentIdentity(); final balance = await p.wallet.getBalance(uid); await p.brain.execute(agent: 'hustle', ...); await p.analytics.screenView(screen: 'home', module: 'hustle');
6Module Integration Rules
  • One YohPalIdentityService — no per-module auth classes
  • One YohPalWalletService — no HustleWallet, JobsWallet, MarketWallet
  • One YohPalBrainGateway — all AI calls routed through it; no direct AI SDK usage in modules
  • One YohPalSearchService — cross-module unified search
  • One YohPalNotificationService — no per-module push logic
  • One YohPalAnalyticsService — all events go to platformAnalyticsEvents
  • One YohPalDeepLinkService — yohpal:// scheme for all cross-module navigation
  • Each migrated module registers a YohPalModuleMigrationAdapter in the YohPalEcosystemMigrationRegistry
