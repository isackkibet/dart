2Platform Registry

The registry is the single entry point for all platform capabilities. Modules receive it via Provider and access shared services exclusively through it.

// lib/platform/platform_registry.dart // Usage in a module: // final platform = context.read<YohPalPlatformRegistry>(); // final identity = await platform.identity.getCurrentIdentity(); // final balance = await platform.wallet.getBalance(identity!.uid); class YohPalPlatformRegistry { final YohPalIdentityService identity; final YohPalWalletService wallet; final YohPalNotificationService notifications; final YohPalSearchService search; final YohPalBrainGateway brain; final YohPalAnalyticsService analytics; final YohPalDeepLinkService deepLinks; }

4Module Integration Rule

Prohibited — duplicate platform services

  • LiveWallet · HustleWallet · JobsWallet · MarketWallet
  • LiveAI · JobsAI · HustleAI · YciosAI
  • LiveNotifications · HustleNotifications
  • Module-local authentication logic

Required — one platform, one service each

  • One YohPalIdentityService — SSO across Live, Jobs, Hustle, Market, YCIOS
  • One YohPalWalletService — single ledger, single reconciliation
  • One YohPalBrainGateway — all AI calls route here
  • One YohPalSearchService — creators, jobs, products, videos
  • One YohPalNotificationService — push & in-app hub
  • One YohPalAnalyticsService — unified event schema
  • One YohPalDeepLinkService — yohpal:// scheme
// Every module accesses shared services this way — no exceptions final platform = context.read<YohPalPlatformRegistry>(); final identity = platform.identity; final wallet = platform.wallet; final brain = platform.brain; final search = platform.search; final analytics = platform.analytics;
