BLOCKER 2 — Infinite Recursion in YohPalPeerFactory.createPeerConnection() FIXED

Previous: Factory method recursively called itself → StackOverflow on every peer connection creation.
Current: Method renamed to buildPeerConnection(). Calls rtc.createPeerConnection() from flutter_webrtc — no self-reference. Both broadcaster (line 70) and viewer (line 97) controllers call it correctly.

BLOCKER 3 — DTLS Echo Bug FIXED

Previous: Client echoed server's DTLS fingerprint → no media flow, no video delivery.
Current: YohPalDtlsHelper.extractDtlsParametersFromSdp() extracts the client's own fingerprint from the local SDP offer. Both broadcaster controller (lines 82-90) and viewer controller (lines 116-124) create an offer, set local description, extract client fingerprint, and send it to the server via connectTransport.

BLOCKER 4 — Deprecated Color.withOpacity() FIXED

Previous: 9 occurrences of deprecated withOpacity() → build warnings, Flutter 4 build failure.
Current: 0 occurrences of withOpacity in the entire modules/live-streaming/ directory. All 9 call sites migrated to withValues(alpha: ...) across theme, status pill, home screen, error panel, and action button files.

MEDIUM — No Signaling Timeout FIXED

Previous: Signaling requests had no timeout → UI could hang indefinitely.
Current: request() method has Duration(seconds: 10) default timeout. Uses .timeout() with TimeoutException and pending-request cleanup via YohPalRequestTracker.

MEDIUM — YohPalRemoteMediaAttacher Dead Code FIXED

Previous: Class existed but was unused.
Current: Wired into viewer controller (line 101) — onTrack callback calls YohPalRemoteMediaAttacher.attachTrack() for every video track received.
