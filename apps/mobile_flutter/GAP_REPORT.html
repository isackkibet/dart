ID Severity Version Gap Description Owner / Path
G-01 Critical V4 NestJS pipeline disconnected from Firebase Storage. Production videos exist in yohlab.firebasestorage.app; the NestJS feed reads from local disk and returns an empty array. A Firebase Storage adapter must be written for the feed to serve real content. backend/video-pipeline/src/modules/storage/
G-02 Critical V8 HLS output naming mismatch. Pipeline generates index.m3u8 + 360p/index.m3u8; production bucket uses master.m3u8 + playlist_360p.m3u8. Paths must be aligned before the pipeline can write HLS that the CDN can serve. hls.service.ts · transcode.worker.ts
G-03 Critical V8/V9 CDN manifest rewrite missing. The master.m3u8 on cdn.stream.yohpal.com references variant playlist URLs on firebasestorage.googleapis.com, not cdn.stream.yohpal.com. Segment fetches bypass CDN cache and incur Firebase egress costs. YohPalStreamProvider.sign()
G-04 Critical V10/V11 No certification sessions submitted. Both Android and iOS 30-minute stability tests are outstanding. certifiedForControlledRelease remains false; the V11 release gate blocks all rollout until these pass. POST /video-performance/metrics
G-05 Critical V11 Release lock not approved. All 12 boolean gates in YohPalVideoReleaseLock remain false. No approver name, role, or rollout percentage has been set. YohPal Live cannot enter controlled rollout. services/release-control/
G-06 High V4 Cloud Functions not implemented: gift-to-earnings conversion, wallet balance aggregator, ad billing deduction, and M-Pesa payout trigger are all pending. Financial flows are incomplete for the attention economy. functions/ (pending)
G-07 High V2 iOS Swift native bridge Xcode target membership not re-verified after recent project changes. V2 ExoPlayer/AVPlayer native files may be excluded from the iOS build target. ios/Runner.xcodeproj
G-08 High V11 networkType is hardcoded '4g' in VideoFeedService.getSmartFeed(). The actual device network type is never passed to the delivery decision, so 3G/low-data HLS quality switching cannot trigger. video-feed.service.ts:70
G-09 High V4/V9 Video buffering observed on fresh app launch (spinner visible in live session). The feed returns real Firebase-hosted videos but no Firestore-to-NestJS bridge exists — the app is loading video URLs from a different code path than the NestJS engine. lib/core/video/ · feed integration
G-10 Medium V11 _userId parameter in getSmartFeed() is unused. Feed ranking is not personalised per user — all users receive the same global ranking. User-specific watch history and preferences are not factored in. video-feed.service.ts:43
G-11 Medium V10 Performance certification HTML dashboard not published as a live artifact. Engineers must use raw curl commands against the API to check certification status. No visual summary is accessible to non-engineering reviewers. services/video-intelligence/
G-12 Medium V8 'auto' is present in the YohPalDeliveryDecision.recommendedQuality type union but is no longer produced by the updated decision service. The stale type creates a false contract in downstream consumers. delivery-decision.service.ts:12
G-13 Low V7 Telemetry retry scheduler not wired to a background isolate or WorkManager job. Offline events are only synced when the user opens the app. Events may be lost if the app is uninstalled before the user returns. yohpal_telemetry_sync_service.dart
