Calls recalculateWalletBalance(creatorId): queries all creatorEarnings for the creator, runs pure aggregateEarnings() (zero I/O, 5 unit-tested cases), writes walletBalances/{creatorId} with available (= approved earnings), pending, paid, lifetime, currency. WalletScreen now displays real KES balances. Closes the HIGH gap identified in v7 — wallet aggregation CF now live.

On any status transition (pending→approved, approved→paid), calls recalculateWalletBalance so creator's available balance updates in real-time after admin approval. Writes revenueAuditLogs entry with old + new status on every transition.
