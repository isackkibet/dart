Phase 7F — Cloud Functions Architecture (3 CFs deployed · europe-west2)
LIVE

creatorAdRevenueProcessor

onDocumentCreated('rewardedAdEvents/{eventId}'). Reads liveSessions.viewerCount. Resolves tier via resolveCreatorTier(). Below 100 viewers → writes lock with eligible: false, no earnings. At/above threshold → writes creatorEarnings (source=rewarded_ad, status=pending), increments creatorAdEarningStats, writes creatorRevenueAuditLogs. Idempotency key: eventId_creatorId.

LIVE

couponRedemptionCommissionProcessor

onDocumentUpdated('smartCoupons/{couponId}'). Fires only on before.status ≠ 'redeemed' AND after.status = 'redeemed' (exact once). Idempotency lock: couponCommissionProcessed/{couponId}. Reads campaign.couponRedemptionCommissionAmount. Writes creatorEarnings (source=coupon_redemption), increments creatorAdEarningStats.couponRedemptionCommission + couponsRedeemed, writes audit log.

LIVE

creatorReputationScoreUpdater

onDocumentWritten('creatorProfiles/{creatorId}'). Computes weighted score: (contentQuality + audienceRetention + watchCompletion + communityCompliance) × 0.2 each + businessVerified bonus (10) − fraudScore × 0.2. Grades: bronze(<60) silver(60–69) gold(70–79) diamond(80–89) elite(90+). Writes creatorReputationScores via Admin SDK (write-locked to mobile).
